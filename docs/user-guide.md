# 只读版本使用说明

## 启动与扫描

在项目目录运行 `./script/build_and_run.sh`，或使用 Codex Run。需要本项目固定的 Xcode；脚本不安装工具、不修改全局工具链。首次打开处于未扫描状态，数量未知。

在窗口的扫描区域选择来源目录和应用索引目录，然后主动开始只读扫描。目录授权不保存为长期 bookmark。支持当前用户的启动配置、共享启动配置和限定应用目录；不扫描其他用户私有目录。系统或沙箱拒绝访问会显示覆盖缺口，不会当作没有记录。取消扫描保留明确的取消状态；再次扫描会创建新代次。

本版只读取启动配置、有限应用身份及静态签名元数据。不会启动被检查软件或读取权限数据库。签名元数据不等于验证签名可信，也不证明应用归属。真实记录不开放清理复选框；来源不全时不会判定为高可信残留。差异中的“本次未观察到”不等于文件被删除。

## 查看记录与报告

分类页面可查看记录、来源和限制。总览始终展示覆盖状态，部分覆盖不是系统完整清单。真实或合成测试扫描结束后，可以查看脱敏 JSON/CSV 报告并手动选择复制。默认省略软件名称、标识和路径，不输出原始权限记录。JSON 包含覆盖摘要；CSV 是逐记录表，保留数据来源标签。报告不是执行计划，不能导入清理。

## 合成演示

载入演示会明确显示合成标识，不读取主机数据。手动选择合成项目后，可以查看实际影响范围、批准范围扩大并演练确认。全部影响对象为可操作高可信残留时一次确认；包含已安装软件时必须两次独立确认。未知、受保护或范围不明的对象会阻断。改变选择或计划使原确认失效。最终只生成 dry-run 结果，不改变系统。

## 权限、后台组件与隐私

权限分类仅提供能力说明与系统设置核对路径；不提供全量重置或绕过 TCC 的入口。登录项、BTM 和 runtime 尚无完整验证的枚举能力，其限制单独呈现。没有特权 helper、登录自启、持续监控或网络遥测。

本版没有真实恢复功能，因为没有执行清理。未来备份也不能承诺恢复旧权限授予。关闭应用即可结束本次使用；没有安装后台组件需要额外卸载。

## 构建与发布

本地预览包位于 `dist/ResidueGuard-development-preview.zip`，是 ad-hoc Debug 包，可能包含调试路径，不应公开发行。正式发布、兼容性、辅助功能人工验收及隔离系统写测试仍未完成。当前实测范围和已知缺口见 [项目当前状态](validation/status.md)。本地开发暂不要求 Developer ID 或 App Store 发布。

## 当前隔离实验的恢复边界

VM 实验已验证自有配置的备份、精确卸载与文件恢复正常路径。恢复当下不自动运行服务；但把配置放回 LaunchAgents 后，下次登录时系统可能重新登记它。RunAtLoad=false 只影响运行触发，不能承诺永不登记。实验能力尚未开放为主界面的真实清理/恢复按钮。
