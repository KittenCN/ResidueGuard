# 本地开发验收范围（2026-09-20）

用户明确暂不考虑 App Store 和 Developer ID。本轮目标为本地运行与可回滚 VM 验收；Developer ID、公证及正式公开分发不作为继续开发的前置条件。`release_check.sh` 保留为未来公开分发检查，不以其预期失败阻断本地开发，也不降低其检查标准。

ad-hoc 可用于当前用户自有夹具和本地应用测试。真实特权 helper 仍需要可核验的调用者身份、明确开发签名 profile 与实际攻击测试；这与是否发布 App Store 是不同问题。未实现 helper 不能归因于缺少 Developer ID，未验证身份不能默认信任。

当前能自主推进的工作：真实目录选择/取消/扫描、严格运行状态解析与精确采集、持久化日志崩溃恢复、只读源备份校验、隔离故障实验、事务执行边界和恢复界面。所有能力按已验证证据逐项推进，不因用户授权开发而自动清理宿主软件。

当前状态以 `status.md` 和各专项实测报告为准。历史文档中“等待 VM 登录”“没有 VM”“journal 未实现”只描述当时状态，不再视作当前阻塞。
