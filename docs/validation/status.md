# 项目当前状态

更新：2026-09-20。目标为本地运行与隔离 VM 验收；用户暂不要求 App Store / Developer ID / 公证分发。**全项目尚未完成，生产系统修改保持关闭。**

- 原生 SwiftUI App 提供真实所选目录只读扫描、合成演示、dry-run、默认脱敏报告与权限引导。
- VM 中实际发现并修复目录已授权却因上级目录读取被拒而返回零行的问题。同一自有配置目录复测返回 1 条；目标未授权仍明确无法核实，不误标高可信残留。真实取消/选择/显式扫描已验证。
- 最新 GUI 11 项回归通过（103.354 秒）；Platform 39 项通过，含运行状态 profile、取消/失败保守降级。Core 30、Security 11 为前轮结果，本轮未修改这些包。
- SQLite 日志已实现：16 项测试通过，其中参数化真实 SIGKILL 覆盖 5 个阶段。持久化重放拒绝与 hot-journal 恢复已验证；不等于断电或完整清理事务验收。
- 新增备份验证包：fd 锚定、内容/元数据指纹、manifest 和读回校验，具体测试与 VM 结果见专项报告。没有隔离/删除/恢复执行 API，不能开启生产清理。
- 真实 XPC helper、完整影响图、精确清理 driver、恢复界面、磁盘满/竞争/服务失败矩阵、多系统兼容性仍未完成。不能将这些开发缺口都归因于签名身份。
