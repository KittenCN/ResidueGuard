# P2 只读来源实现与验证（2026-09-20）

延续用户本轮继续全项目开发的授权；不再受上一轮“只到 P1”任务范围限制，但所有系统写入安全门槛继续有效。环境仍为 macOS27.0 / 26A428、arm64、Xcode27.0 / 27A266a、Swift6.4、SDK27。

## 已实现范围

独立 `ResiduePlatform` 包提供限量、可取消的启动 plist 与顶层应用索引。逐路径组件 `O_NOFOLLOW`，拒绝特殊文件；文件上限、条目上限、最多每类16根、16MiB总读取预算、4KiB原始来源预览、完整内容摘要均显式影响覆盖。解析失败保留来源行，不静默丢弃。应用多实例保留路径、文件/卷身份；签名未验证明确标记。真实分类不会仅凭文件缺失标为高可信残留。

固定只读诊断 runner 分开捕获 stdout/stderr/退出码，公平有界读取、超时、取消及输出截断；只停止其自己启动的诊断子进程，不卸载任何服务。没有任意 executable/shell 的公开接口。不读取 TCC/BTM 数据库。未接入的 runtime/BTM/登录项/权限来源返回 unsupported，不伪装空列表成功。

GUI 保持沙箱，仅请求用户所选目录的只读访问。目录选择与开始扫描分开；不持久化授权。仅允许当前用户或标准系统启动配置目录，拒绝其他用户私有目录。真实行不可勾选；演示切换清除选择/计划。复扫比较的“未再次观察”不等于删除。

## 实际验证

- `./script/test.sh core`：12 个核心测试通过，含2个快照比较测试及既有24条确认 fixture。
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --package-path Packages/ResiduePlatform`：最终18个测试通过，包含6个诊断子进程测试、解析/特殊文件/符号链接/取消/根目录和元数据边界。
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift run --package-path Packages/ResiduePlatform ResidueProbe --host-readonly`：实际只读主机采集成功；14条配置记录（含2条失败来源行）、43个应用实例、0高可信残留。

主机结果只输出计数，无软件名或个人路径：应用索引两根分别 partial(42解析/6错误)、partial(1解析/5错误)；三个启动根分别 completeWithinDeclaredScope(2解析)、partial(5解析/2失败)、completeWithinDeclaredScope(5解析)。另外4个来源 unsupported。完整范围是本次声明的目录，不是全部系统登记。

初次测试在接口未实现时失败；后续采集 fixture 暴露临时目录系统符号链接与路径规范化问题，已修正测试根并保留禁止跟随符号链接策略。审查修正非阻塞管道失败处理、失败行丢失、聚合预算和错误离线判断。未靠降低保护来让测试通过。

UI 实跑 `./script/test.sh ui`：最终9个 XCUITest 通过，0失败（70.257秒）。新增用例仅注入合成扫描，验证取消、覆盖与模式隔离，不访问主机目录。首轮9项中“过滤隐藏选择”一次断言失败；最终代码重测通过且未放宽断言，确切瞬时失败原因未确定，保留为需关注的 UI 稳定性记录。

`./script/test.sh platform` 最终复跑18项通过（0.125秒），`git diff --check` 通过。GUI构建由UI测试真实完成。旧文档/哈希清理不影响源代码测试。
