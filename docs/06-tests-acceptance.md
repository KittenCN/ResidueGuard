# 06｜测试计划与验收清单

## 6.1 测试层次
核心策略测试使用合成数据、虚拟时钟和可控文件系统，不产生真实系统副作用。采集器解析测试使用脱敏 fixture，并锁定 OS build/source profile。系统行为和特权测试必须在可回滚 macOS VM或专用测试账号中完成。GUI 测试使用 mock provider，以确定按钮次数、选择状态和可访问性。

测试覆盖的百分比不能替代危险分支的直接验证。每个对系统开放的修改路径，都必须有真实平台前后状态证据。Linux 的 bash 语法检查不算 macOS 构建或集成验证。

## 6.2 确认规则（最高优先级）
| ID | 情形 | 必须结果 |
|---|---|---|
| C01 | 没有勾选 | 清理入口禁用，不弹确认 |
| C02 | 一项可执行红色残留 | 应用内一次确认 |
| C03 | 多项可执行红色残留 | 整批一次确认，不逐项重复 |
| C04 | 一项仍安装软件 | 两次独立应用内确认 |
| C05 | 全部仍安装软件 | 整批两次确认 |
| C06 | 红色残留 + 仍安装软件混选 | 两次确认 |
| C07 | 只有疑似/未知项 | 阻断，不允许靠双确认越过 |
| C08 | 保护/MDM 项 | 无法勾选；伪造计划仍被拒绝 |
| C09 | 残留但只支持系统设置 | 不可执行，提供引导 |
| C10 | 红色关系行的实际操作影响已安装调用者 | 未明确扩大范围则阻断；重新批准扩大计划后两次确认 |
| C11 | 确认后改勾选/动作 | 所有已完成确认失效 |
| C12 | 确认后文件被替换或 app 重装 | 终止旧计划；不清理新对象 |
| C13 | 第一次确认按钮双击/连续 Enter | 不跳过第二次确认 |
| C14 | 管理员认证成功 | 仍需满足应用内确认次数，不可抵扣 |
| C15 | 管理员认证取消 | 此计划尚未执行的系统修改为零 |
| C16 | 同页过滤隐藏已勾选项 | 显示隐藏勾选数，预览仍列全实际目标 |
| C17 | 切换分类页 | 按 v1 规则清除勾选，不把旧页对象暗中带走 |
| C18 | 两个源观察同一底层配置 | 仅执行一次真实修改，所有关联行有一致结果 |
| C19 | 计划到期/策略变化 | 重新复核并确认 |
| C20 | 重复点击执行或重放 token | 不重复修改 |

随附 `fixtures/confirmation-cases.json` 可导入为基础策略测试，必须再补状态机/UI 测试；JSON 本身不是已实现的测试引擎。

## 6.3 软件存在性与归属
| ID | 情形 | 必须结果 |
|---|---|---|
| I01 | 从 /Applications 移动到获准扫描的其他目录 | 正确找到同身份副本，不标红 |
| I02 | 同 bundle ID 的有效第二安装副本 | 不按原路径缺失判删除 |
| I03 | 同显示名但不同签名身份 | 不相互替代，不错误合并 |
| I04 | 原安装卷未挂载 | volumeUnavailable，不标红 |
| I05 | 原路径 EACCES/EPERM | unknown，不当作 ENOENT |
| I06 | 程序在废纸篓中 | inTrash，不按真正卸载处理 |
| I07 | Homebrew/独立 CLI 服务没有 .app | 有有效程序即不标残留 |
| I08 | 主 app 删除但共享 helper 被其他软件使用 | 共享保护，不清理活跃组件 |
| I09 | 解释器存在、脚本目标缺失 | 按已知解析规则核验真实载荷；未知命令标疑似 |
| I10 | shell -c / 动态环境展开 | 不执行内容；标不确定 |
| I11 | 未签名但真实存在的 app | 显示未签名，不认定删除或恶意 |
| I12 | 更新/安装过程中目标暂时缺失 | 延迟复核或 unknown |
| I13 | 无法解析 alias / symlink 循环 | 返回明确错误，不越界遍历 |
| I14 | 合法大小写敏感文件系统存在相近路径 | 不统一 lowercased 导致错认 |
| I15 | 原 app、载荷均缺失、卷在线、无反证 | 达到规则才 red，理由可审计 |
| I16 | label 冒用 com.apple 或软件名 | 以真实来源/签名/域判断，不按前缀信任 |
| I17 | 服务仍运行但文件已被移除 | 保留运行反证，不当安全空壳清除 |
| I18 | 同 Label 不同 domain/源冲突 | 分开记录，冲突目标不自动执行 |

## 6.4 来源、权限与兼容
| ID | 情形 | 必须结果 |
|---|---|---|
| D01 | BTM 输出新增未知记录类型 | 保留未知行与覆盖警告，禁用相关写能力 |
| D02 | launchctl 命令权限不足 | 区分未知运行状态与未运行 |
| D03 | plist 无法解析/超大/恶意深度 | 安全失败并列出问题文件，不执行载荷 |
| D04 | 同时读取多个来源部分失败 | 显示部分结果及缺口，而非全局成功 |
| D05 | macOS 27 TCC 直读路线 | 未调用绕过读取；页显示限制而非 0 应用 |
| D06 | 旧版 TCC schema 改变 | 显式降级，不用错误字段解读授权 |
| D07 | 用户拒绝额外权限 | 工具仍可使用基本扫描，不重复骚扰弹窗 |
| D08 | tccutil 对已卸载 bundle 返回找不到 ID | 失败并手动引导，不全量重置 |
| D09 | reset 返回成功，但无法读取后置状态 | issued/unverified，不伪造“条目已移除” |
| D10 | 自动化仅一条 caller-target 被选择 | 不扩大到调用者全部权限，除非新计划明确授权且范围可知 |
| D11 | 本地网络/定位页面 | 不使用猜测的 TCC token |
| D12 | 导入历史权限快照 | 标明时间与非实时；不可直接执行 |
| D13 | 读取到其他用户记录 | 按授权范围排除，不泄露原始日志 |
| D14 | 子进程超时或输出超限 | 取消/partial，主线程可交互 |
| D15 | 深链接失效/系统设置 UI 改名 | 提供文字路径，保持手动流程可用 |
| D16 | 新 OS build 未验证 | 只读降级，不静默启用旧写策略 |

## 6.5 清理、备份与竞争
| ID | 情形 | 必须结果 |
|---|---|---|
| M01 | 正常用户 LaunchAgent 残留 | 备份 → 精确卸载 → 隔离 → 验证，均有日志 |
| M02 | 备份磁盘满/权限失败/hash 不一致 | 尚未发生源修改 |
| M03 | bootout 失败或服务身份冲突 | 不继续移除配置 |
| M04 | 配置已被别的工具删除 | 跳过，不删除同名新对象 |
| M05 | 配置已隔离但 BTM 历史仍存在 | 报告来源已清理 + 历史待系统更新 |
| M06 | 每个交易步骤中途强制终止 app/helper | 下次启动准确报告已有动作，无自动继续删除 |
| M07 | 恢复时原位置有新文件 | 不覆盖；显示冲突 |
| M08 | 恢复旧配置 | 验证元数据/身份，不自动启动服务 |
| M09 | 权限重置后点击恢复 | 无假“恢复授权”，解释需系统重新授权 |
| M10 | 同批次第二动作失败 | 按已选择的停止策略执行，未执行项准确标记 |
| M11 | journal 无法写入 | 不开始真实修改 |
| M12 | 共享 Agent 影响其他活跃用户但无法验证 | 阻断，不能声称只影响当前用户 |

## 6.6 特权与输入安全
| ID | 攻击/异常 | 必须结果 |
|---|---|---|
| S01 | 未签名/错误 bundle/错误 Team 客户端 | helper 拒绝连接/请求 |
| S02 | 同 Team 但非授权客户端 | 拒绝，不把 Team 当全部授权 |
| S03 | 伪报 PID/路径/用户身份 | 独立连接身份验证，拒绝 |
| S04 | 任意 path/command 载荷 | 协议无此能力，拒绝未知字段/动作 |
| S05 | path traversal / 绝对路径替换 | 不逃出白名单 |
| S06 | symlink/hardlink/设备文件 | 阻断非预期目标 |
| S07 | 源父目录被低权限用户控制 | root 路径不开放操作 |
| S08 | 计划摘要/nonce/身份被篡改 | 拒绝 |
| S09 | token 过期或重放 | 拒绝或返回旧结果，不重复修改 |
| S10 | 请求其他用户 scope | 拒绝，除已明确批准且验证的机器共享范围 |
| S11 | UI 报 confirmed=true 却无系统授权 | helper 不执行 |
| S12 | CSV 字段是公式/换行/分隔符 | 安全转义，不在打开报告时执行公式 |
| S13 | 日志/导出/崩溃报告含隐私数据 | 按脱敏政策处理，默认不上传 |
| S14 | root 备份目录或 manifest 被替换 | 验证失败，不执行恢复 |

## 6.7 GUI、性能与可访问性
最低验证：原生浅/深色、高对比度、VoiceOver 读出状态与复选框、键盘选择和取消、完整长路径可复制、多语言长文案不截断关键风险、窗口缩小后确认按钮仍可访问。

性能目标（尚未实测，不是承诺）：10,000 条合成记录滚动/筛选不长期阻塞 UI；常规用户操作反馈目标 200ms 内；扫描取消请求目标 1 秒内得到可见反馈；扫描完成耗时按实际目录数/磁盘速度报告，不宣传固定“秒级全盘”。

使用 Instruments/Signposts 找出主线程 I/O、过量签名验证、重复索引和图标加载。若未在 Mac 运行工具，报告 notRun，不能写优化效果百分比。

## 6.8 发布验收矩阵
分别记录 OS 版本/build、硬件架构、Xcode/SDK、签名、账户权限、文件系统大小写、单/多用户、外部卷状态和每一开放 provider 的读/写验证。

功能支持以实际通过的 profile 为准，不把最低 deployment target 视为全功能支持的证据。至少一台干净环境执行首次安装、所有权限拒绝、按需 helper 批准、升级、自卸载、无网络启动。
