# 本地使用说明

当前版本提供只读扫描与预演，**还不能清理真实软件或重置权限**。本地开发与 VM 验收不要求 App Store、Developer ID 或公证。

## 打开应用

在项目根运行 `./script/package_local_release.sh`，得到 `dist/ResidueGuard-local-release.zip` 和校验清单。也可以直接打开构建产物 `.build-xcode/Build/Products/Release/ResidueGuard.app`。主应用必须以普通用户运行。

ZIP 已进行解包签名检查；它使用本地 ad-hoc 签名，没有公开分发的公证证明。另一台 Mac 的下载信任检查尚未验收。构建脚本固定现有 Xcode 基线，不会替用户升级系统或安装工具。

## 查看实际记录

1. 点击“选择启动配置目录”，显式选择允许范围内的 LaunchAgents 或 LaunchDaemons。应用不默认扫描全部主目录。
2. 如需观察安装实例，另点“选择应用索引目录”。应用索引目前只覆盖所选目录的顶层应用，不代表所有安装位置。
3. 点击“开始只读扫描”。在总览核对来源覆盖、错误和未验证区域，再进入对应来源分类查看记录。
4. 点击记录查看证据。查看详情不会自动勾选；所有真实扫描记录的系统修改均禁用。

“未能核实”可能表示没有路径授权、来源解析受限或证据不足，不表示软件已删除。程序当前没有运行，也不等于已卸载。再次扫描时旧结果会清除；取消后可能显示已返回的部分结果。

## 应用候选关联

“应用关联”保留各个观察到的安装实例，展开后查看路径、声明标识、签名标识线索和候选来源。相同应用标识的多个副本不会合并为一个安装实例；同一物理实例的重复观察会保留。

标识相同或程序路径位于应用目录内只是候选理由。签名有效性、实际归属和完整共享关系还没有据此得到证明。冲突、范围不足和处理上限会明确显示。筛选无结果不表示软件已卸载。

## 显式保留记录

在详情中点击“保留这条记录30天”。它只增加保护，不隐藏记录，也不改变原有存在状态。保护匹配后禁止进入预演操作；添加或移除保护会清除旧选择与预演。

在“忽略规则”页查看或移除规则。规则绑定来源标识和内容指纹，到期或内容变化后不再匹配；“本次未观察到”不代表已删除。真实来源规则保存在本应用沙盒配置中，合成演示规则仅保留到当前进程退出。

配置读取失败会显示未知，不当成空配置。保存未确认时先“重新读取本地规则”并核对，不自动重试覆盖。

## 历史、权限与合成预演

- “操作历史与恢复”只导入用户主动选择的受限审计报告，显示脱敏摘要。导入内容的来源未经认证，不会执行、重试或恢复操作，也不代表完整操作历史。
- 权限页提供对应机制的限制与手动核对指引。没有第三方权限总表，也不读取 macOS 27 的 TCC 数据库。
- “载入合成演示”用于检查选择、影响展开和独立确认流程。演示确认不会修改真实系统，不生成后续清理授权。
